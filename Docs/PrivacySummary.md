# Privacy Summary

Unity Interview Prep (Gold Box) stores learning progress on-device only for this MVP.

## Data stored locally

- Study progress (questions answered, ratings, confidence)
- Bookmarks and lesson completion
- Flashcard spaced-repetition scheduling
- Mock interview history and interrupted session state
- Preferences (daily goal, think time, reduced motion, haptics)

## Not collected by the app MVP

- Name/email account registration
- Analytics event streams to third parties
- Advertising identifiers for ads (no ads)
- Precise location

## Controls

Progress is stored only on this device. Deleting the app removes local progress. No personal identity data is collected by the app itself.

If future versions add cloud sync, accounts, or analytics, this document and the store privacy nutrition labels will be updated before shipping that change.
